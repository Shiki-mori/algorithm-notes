# 输出样例

材料对应 `leetcode/p0062_unique_paths/`：DFS、二维 DP、组合数三解。

## 整题

用户：「这题我要掌握到什么程度？」

```markdown
## 掌握建议：62. Unique Paths

- 范围：整题
- 总体：必须手写
- 主推解法：`uniquePathsDP` — 必须手写

### 笔试
网格 DP 中高频。限时写二维 DP：首行首列初始化为 1，其余 `dp[i][j] = 上 + 左`。不要交未记忆化 DFS。

### 面试
先讲递推和边界，再说可压成一维。组合数作为追问：向下 `m-1`、向右 `n-1`，共 `C(m+n-2, m-1)`。能对上 DP 即可，不要求现场推连乘除防溢出。

### 各解法
| 解法 | 等级 | 一句话理由 |
| --- | --- | --- |
| `uniquePaths`（DFS） | 了解即可 | 引入用，数据范围必 TLE，不当主解 |
| `uniquePathsDP` | 必须手写 | 笔试稳过、面试主讲，网格 DP 模板可迁移 |
| `uniquePathsComb` | 必须讲清 | 常见追问；默写组合数细节易错，不抬成主解 |

### 投入
- 先做：默写二维 DP，并能口述空间压缩
- 可后做 / 可放下：DFS 不用再刷；组合数会讲等价关系即可
```

## 特定解法

用户：「组合数那版要不要会手写？」

```markdown
## 掌握建议：62. Unique Paths / `uniquePathsComb`

- 范围：特定解法
- 该解法：必须讲清
- 相对本题其他解法：备选（主推仍是 DP）
- 手写还是讲清：必须讲清

### 笔试
不作为第一选择。会写 DP 即可过；组合数连乘除容易溢出或除不尽写错。

### 面试
要能说出「路径条数 = 组合数」以及和 DP 的对应。被要求写代码时，优先回到 DP，再补一句公式。

### 理由
- 相对 `uniquePathsDP` 是加分追问，不是过题主解
- 迁移价值偏数学，对其他网格 DP 题帮助不如递推模板

### 投入
- 把时间留给 DP 默写；组合数只记公式与等价关系
```
