# 题解：Increasing Triplet Subsequence

判断数组中是否存在下标 `i < j < k`，使得 `nums[i] < nums[j] < nums[k]`。不要求连续。

## 思路

### 双向极值：左边最小值 + 右边最大值

枚举中间下标 `j`。只要左边存在比 `nums[j]` 更小的数，右边存在比它更大的数，就构成递增三元组。

预处理：

- `leftMin[i]`：`nums[0..i]` 的最小值
- `rightMax[i]`：`nums[i..n-1]` 的最大值

然后检查 `1 <= j <= n-2`：

```text
leftMin[j - 1] < nums[j] < rightMax[j + 1]
```

注意 `leftMin[j]` 含 `nums[j]` 自己，比较时要用 `leftMin[j - 1]`；`rightMax` 同理。

两个数组可以在同一趟循环里填。从右往左填 `rightMax` 时，必须取当前位置的值：

```java
rightMax[n - 1 - i] = Math.max(rightMax[n - i], nums[n - 1 - i]);
```

若误写成 `nums[i]`，填的就不是「右侧最大值」，会漏判或误判。例如 `[5, 1, 2, 3, 0]` 存在 `1 < 2 < 3`，写错会返回 `false`；`[1, 10, 5, 3, 2]` 没有三元组，写错会返回 `true`。

对应实现见 `increasingTriplet`。

### 贪心：维护两个递增候选

进阶要求 `O(1)` 空间。从左到右扫一遍，只记两个变量：

- `first`：当前最优的三元组起点（目前见到的最小候选）
- `second`：已经出现过的递增二元组里，较大那个数能小到多少

遇到 `nums[i] > second`，说明已经有 `first < second < nums[i]`，返回 `true`。

更新规则（严格大于，因为题目要求严格递增）：

1. `nums[i] > second`：找到第三个数，返回 `true`
2. `first < nums[i] <= second`：把 `second` 收得更小，后面更容易接上第三个数
3. `nums[i] <= first`：只更新 `first`，给后面准备更好的新一对

对应实现见 `increasingTripletGreed`。

### 为什么 first 可以出现在 second 后面

`first` 和 `second` **不是**「当前这一对下标」。`second` 一旦被赋过值，只说明前面已经出现过一个比它小的数；之后改 `first`，是在给后面准备更好的新一对，旧的那一对仍然有效。

以 `[20, 100, 10, 12, 5, 13]` 为例：

| 走到 | first | second | 发生了什么 |
| --- | --- | --- | --- |
| `20` | `20` | `∞` | 起点 |
| `100` | `20` | `100` | 找到一对 `20 < 100` |
| `10` | `10` | `100` | 只改 `first`。此时 `10` 在 `100` 后面 |
| `12` | `10` | `12` | 用新的 `10 < 12` 换掉旧的 `second` |
| `5` | `5` | `12` | 再准备一个更小的起点 |
| `13` | — | — | `13 > 12`，返回 `true`（`10 < 12 < 13`） |

第三步最容易误会：变量变成了 `first = 10`（下标 2）、`second = 100`（下标 1），下标是反的。这时如果后面出现 `101`，三元组是 **`20 < 100 < 101`**，用的是改 `first` **之前**记下的那一对，不是 `10` 和 `100`。`10` 只是候选，还没接上第二个数。

因此两个变量的真实含义是：

- **`second`**：已经出现过递增二元组，较大那个数可以小到这么多
- **`first`**：目前看到的最小起点，用来组成**下一对**可能的 `(first, second)`

更新 `first` 不会把已经成立的那对抹掉。后面只有两条路：

1. 来一个 `> second` 的数：直接用**旧对**接上第三个数
2. 来一个 `first < x <= second` 的数：用**新的 `first`** 配上这个 `x`，得到更小的 `second`

两种情况下，真正用来返 `true` 的三个数，下标仍然递增。

## 复杂度

双向极值：

- 时间：O(n)，预处理两次数组，再扫一遍中间位置
- 空间：O(n)，`leftMin` 与 `rightMax`

贪心：

- 时间：O(n)，一次遍历
- 空间：O(1)

## 关键点

- 子序列不要求连续，只需下标递增且值严格递增。
- 双向极值枚举的是中间元素；`leftMin` / `rightMax` 比较时不要含当前下标自己。
- 从右往左填 `rightMax` 时用 `nums[n - 1 - i]`，不能写成 `nums[i]`。
- 贪心里 `first`、`second` 是候选值，不是固定下标对；`first` 可以出现在 `second` 后面。
- 用严格 `>` 更新，相等不能当第三个数。
- `second` 越小，后面越容易接到第三个数，所以中间那档要尽量把 `second` 收小。
