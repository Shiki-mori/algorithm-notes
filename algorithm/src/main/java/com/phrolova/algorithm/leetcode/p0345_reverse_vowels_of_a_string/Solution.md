# 题解：Reverse Vowels of a String

## 思路

只反转元音，辅音和标点原位不动。用双指针从两端向中间收，每次只处理当前这一对位置。

1. 把字符串拷进 `StringBuilder`，方便原地改字符。
2. 用 `HashSet` 存 10 个元音：`a e i o u` 及其大写。
3. 左指针 `i` 从 0、右指针 `j` 从末尾出发，`i < j` 时分四种情况：
   - **两边都是元音**：交换，然后 `i++`、`j--`
   - **只有左边是元音**：`j--`，继续找右边的元音
   - **只有右边是元音**：`i++`，继续找左边的元音
   - **两边都不是元音**：`i++`、`j--`

对应实现见 `reverseVowels`。四种情况互斥，每一轮只移动「当前还不是元音」的那一侧；两侧都命中才交换，交换后两边各走一步。

等价写法是先排除非元音，再交换：

```java
while (i < j) {
    if (!set.contains(str.charAt(i))) {
        i++;
    } else if (!set.contains(str.charAt(j))) {
        j--;
    } else {
        swap(str, i++, j--);
    }
}
```

### 示例

`s = "IceCreAm"`，元音序列 `['I', 'e', 'e', 'A']`：

1. `I` 与 `A` 交换 → `"AceCreIm"` 的两端已就位
2. 中间一对 `e` 与 `e` 交换，结果不变
3. 得到 `"AceCreIm"`

## 复杂度

- 时间：O(n)，每个下标最多被访问常数次
- 空间：O(n)，`StringBuilder` 拷贝；元音集合大小固定为 10，可视为 O(1)

## 关键点

- 元音集合必须同时包含大小写，漏掉 `I` / `A` 会在 `"IceCreAm"` 这类用例上出错。
- 每次只移动非元音一侧。若在 `swap(str, i++, j--)` 之后再统一 `i++; j--;`，或「只找到右侧元音」时仍执行 `j--`，会跳过尚未交换的元音（例如 `"Marge, let's \"went.\" I await news telegram."` 中的 `I` 与 `i`）。
- `continue` 只是为了跳过「左元音、右非元音」之后的多余移动；若循环末尾不再统一加减指针，四种情况各自移动即可，不必再 `continue`。
- `else if` 里再判断「左边也是元音」是死分支：能走进该分支时左边一定不是元音。
