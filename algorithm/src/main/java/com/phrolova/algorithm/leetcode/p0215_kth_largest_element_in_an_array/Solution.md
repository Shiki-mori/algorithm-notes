# 题解：Kth Largest Element in an Array

## 思路

### 大顶堆 + 取 k-1 次最大值

本题不要求完整排序，只需找到第 `k` 大的元素。用大顶堆维护「当前未取出元素中的最大值」，重复取出堆顶即可。

**核心步骤：**

1. **建堆** `buildMaxHeap`：将数组调整为一个大顶堆，`a[0]` 为当前最大值。
2. **取 k-1 次最大值**：每次将堆顶 `a[0]` 与末尾交换，缩小堆规模 `heapSize--`，再对新的堆顶 `maxHeapify(0)` 下沉恢复堆性质。
3. **返回堆顶** `a[0]`：此时堆顶即为第 `k` 大的元素。

对应实现见 `findKthLargestHeapSort`。

### 大顶堆（数组表示）

用数组表示完全二叉树，节点 `i` 的下标关系：

- 左孩子：`2 * i + 1`
- 右孩子：`2 * i + 2`

大顶堆性质：每个父节点 ≥ 其左右孩子，因此堆顶 `a[0]` 始终是堆内最大值。

### `maxHeapify`：下沉，维护堆性质

假设节点 `i` 的左右子树已是合法堆，但 `a[i]` 可能小于孩子。从 `i` 出发：

1. 在 `i`、左孩子、右孩子中找最大值下标 `largest`。
2. 若 `largest != i`，交换 `a[i]` 与 `a[largest]`，并对 `largest` 递归下沉。

`heapSize` 表示当前堆的有效长度，末尾已取出的元素不再参与堆操作。

### `buildMaxHeap`：O(n) 建堆

从最后一个非叶子节点 `heapSize / 2 - 1` 开始，依次向前对每个节点调用 `maxHeapify`。

叶子节点（下标 ≥ `heapSize / 2`）本身已是堆，无需处理。

### 与完整堆排序的区别

完整堆排序需重复 `n - 1` 次「堆顶 ↔ 末尾 + maxHeapify」，最终得到升序数组。

本题只需执行 `k - 1` 次，堆顶即为第 `k` 大，无需排完全部元素。

### 示例

`nums = [3, 2, 1, 5, 6, 4]`，`k = 2`：

1. 建堆后堆顶为 `6`。
2. 第 1 轮：堆顶 `6` 换到末尾，`maxHeapify` 后堆顶变为 `5`。
3. 返回 `a[0] = 5`。

## 复杂度

- 时间：O(n + k log n)。建堆 O(n)，取 k-1 次最大值每次 `maxHeapify` 为 O(log n)。
- 空间：O(log n)，`maxHeapify` 递归栈深度；若改为迭代可降至 O(1)。

## 关键点

- 大顶堆堆顶是当前最大值；取走堆顶后必须 `maxHeapify` 恢复堆性质。
- `heapSize` 随每次取出而缩小，已放到末尾的元素不再参与堆操作。
- 循环 `k - 1` 次后，堆顶即为第 `k` 大，不是完整堆排序。
- `buildMaxHeap` 从 `heapSize / 2 - 1` 倒序建堆，整体为 O(n)，不是 n 次 O(log n) 的简单相加。
