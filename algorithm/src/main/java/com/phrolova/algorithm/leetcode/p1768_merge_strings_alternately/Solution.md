# 题解：Merge Strings Alternately

## 面试评价（总体）

**结论：通过。** 在 LeetCode 给定的 `mergeAlternately` 方法体内，思路正确、实现可运行，三个官方示例及等长边界均正确。属 Easy 题的合格作答；尚有少量可读性/小瑕疵可追问打磨。

> 评价范围：仅方法 `public String mergeAlternately(String word1, String word2)` 内部实现（与平台骨架一致），不评价类名、包名、`main` 等骨架外内容。

## 思路

1. 取较短串长度，用同一下标交替 `append` 两串字符
2. 较长串剩余后缀一次性接到结果末尾
3. 等长时两个 `if` 均不进入，直接返回

与标准线性解一致，题意理解到位，无过度设计。

## 复杂度

- 时间：O(n + m)
- 空间：O(n + m)（结果串；`StringBuilder` 同阶）

符合期望。

## 亮点

- 使用 `StringBuilder`，避免字符串反复拼接
- 等长 / 左长 / 右长三类情况覆盖完整
- 结构简单，与题目难度匹配

## 可改进点（非阻断）

1. **`substring(i++)` 中的自增无意义**  
   循环结束后 `i` 已是后缀起点，应写 `substring(i)`。`i++` 不改变拼接结果，却引入无用副作用，面试中可追问「这里加一有什么作用」。

2. **最短长度写法可更清晰**  
   `(word1.length() < word2.length() ? word1.length() : word2.length())` 可改为 `Math.min(word1.length(), word2.length())`，条件表达式嵌在 `for` 里略挤。

3. **可选写法**  
   双指针一边扫一边补齐、省掉显式 `substring`，也是常见变体；当前写法完全可接受。
