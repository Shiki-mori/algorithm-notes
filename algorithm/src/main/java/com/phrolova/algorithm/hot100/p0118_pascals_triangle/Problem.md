# 118. Pascal's Triangle

- 难度：Easy
- 标签：Array, Dynamic Programming
- 链接：https://leetcode.cn/problems/pascals-triangle/

## 题目描述

给定一个非负整数 *`numRows`，*生成「杨辉三角」的前 *`numRows` *行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

## 示例

**示例 1:**

```text

输入: numRows = 5
输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

```

**示例 2:**

```text

输入: numRows = 1
输出: [[1]]

```

## 约束

- `1 <= numRows <= 30`
