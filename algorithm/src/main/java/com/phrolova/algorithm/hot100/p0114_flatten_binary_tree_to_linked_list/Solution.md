## 思路

### 反向后序递归

先序 根-左-右，反过来是 右-左-根，相当于从链表尾部向前连接。

用next记录上一个处理的节点，即当前节点的后继。

### 找前驱节点

先序遍历中，左子树全部访问完后访问右子树。

左子树最后访问的节点，是从左孩子开始一直向右走到底的节点，将右子树接到该节点后即可。该节点称为前驱节点。

## 复杂度

- 时间：三种解法均为 O(n)
- 空间：先存后连为 O(n)；反向后序递归为 O(h)，h 为树高；找前驱节点为 O(1)
