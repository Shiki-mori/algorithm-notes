# 226. Invert Binary Tree

- 难度：Easy
- 标签：Tree, Depth-First Search, Breadth-First Search, Binary Tree
- 链接：https://leetcode.cn/problems/invert-binary-tree/

## 题目描述

给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。

## 示例

**示例 1：**

```text

输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]

```

**示例 2：**

```text

输入：root = [2,1,3]
输出：[2,3,1]

```

**示例 3：**

```text

输入：root = []
输出：[]

```

## 约束

- 树中节点数目范围在 `[0, 100]` 内
- `-100 <= Node.val <= 100`
