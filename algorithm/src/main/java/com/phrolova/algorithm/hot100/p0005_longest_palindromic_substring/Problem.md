# 5. Longest Palindromic Substring

- 难度：Medium
- 标签：Two Pointers, String, Dynamic Programming
- 链接：https://leetcode.cn/problems/longest-palindromic-substring/

## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

## 示例

**示例 1：**

```text

输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。

```

**示例 2：**

```text

输入：s = "cbbd"
输出："bb"

```

## 约束

- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成
