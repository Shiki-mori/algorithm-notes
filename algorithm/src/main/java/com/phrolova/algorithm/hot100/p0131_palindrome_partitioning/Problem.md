# 131. Palindrome Partitioning

- 难度：Medium
- 标签：String, Dynamic Programming, Backtracking
- 链接：https://leetcode.cn/problems/palindrome-partitioning/

## 题目描述

给你一个字符串 `s`，请你将`s`分割成一些 子串，使每个子串都是 回文串 。返回 `s` 所有可能的分割方案。

## 示例

**示例 1：**

```text

输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]

```

**示例 2：**

```text

输入：s = "a"
输出：[["a"]]

```

## 约束

- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成
