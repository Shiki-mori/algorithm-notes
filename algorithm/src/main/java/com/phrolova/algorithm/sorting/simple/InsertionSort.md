# 插入排序

## 算法描述

### 交换式插入排序

输入一个数组arr[]

0有序  
0~1有序：从arr[1]开始，向前比较，逐个交换，直到有序；  
0~2有序：从arr[2]开始，向前比较，逐个交换，直到有序；  
...  
0~n-1有序

0~i有序：arr[i]开始，与arr[i-1]比较。  
若arr[i-1]>arr[i-0],则交换位置。  
随后arr[i-2]与arr[i-1]比较，直到arr[i-(j+1)]<=arr[i-j]。

### 移动式插入排序

0~i有序：  
先保存当前arr[i]的元素。让前面更大的元素整体后移，最终一次性插入。

```text
current=3
2,4,5,3
2,4,5,5
2,4,4,5

2,3,4,5
```

## 复杂度

最坏时间复杂度：O(n^2)  
最好时间复杂度：O(n)
